# Differentiable D3 — Recovering parameters from a morphology

The first true **inverse problem**. Given a target morphology (here
generated by a known ground-truth material), recover the material
parameters $(\chi,\kappa)$ that produced it by gradient descent on the
field misfit, using the adjoint gradient. This is the tutorial-scale
version of *learning the material from the morphology* — the loop that,
at research scale, fits a free-energy functional to measured micrographs.

**Read** the course document, Chapter *"Recovering parameters from a
morphology"* (start with `recover.py`).

**Run:**
```bash
python run.py                 # recover (chi, kappa) from a morphology
python run.py --steps 8
```

`run.py` first FD-verifies the fitting-loss gradient, then runs L-BFGS-B
and asserts the loss collapsed and $(\chi,\kappa)$ reached truth; compare
with [`EXPECTED.md`](EXPECTED.md).

**Regenerate the document's figures + numbers** (optional):
```bash
python gen_figures.py         # writes ../../latex/figures/d3_descent.png + numbers/d3.tex
```

| file | role |
|------|------|
| `recover.py` | the core: `recover`, `loss_and_grad`, `fd_check` — read this first |
| `run.py` | the driver; gradient self-check + recovery, with assertions |
| `gen_figures.py` | regenerates `d3_descent.png`, `numbers/d3.tex` |
| `EXPECTED.md` | reference recovery your run should reproduce |

Same production adjoint (`src/diffsim/adjoint/phasefield.py`); the
optimiser is stock `scipy.optimize.minimize` (L-BFGS-B).
