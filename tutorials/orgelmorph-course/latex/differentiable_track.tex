\chapter{What differentiable simulation is}
\label{ch:d1}
\begin{keybox}
\textbf{Key idea.} A classical solver answers \emph{``what happens?''}.
A differentiable solver also answers \emph{``what should I change?''} ---
it returns the gradient of any output with respect to any input
(material parameters, process schedule, geometry), so the simulator
becomes an instrument for design and inference, not just prediction.
\end{keybox}
This concept introduces the three ways DiffSim computes a gradient ---
a hand-derived adjoint, an autograd twin, and finite differences ---
and the three-way check that keeps them honest. \emph{Under
construction.}
