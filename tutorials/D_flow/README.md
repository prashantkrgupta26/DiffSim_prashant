# Track D — Incompressible flow

Part of the [DiffSim curriculum](../README.md). Every chapter is a runnable,
self-contained script: *Learning outcome → Background → documented code →
Expected results (measured numbers you must reproduce) → Explore.*

| ch | script | outcome |
|---|---|---|
| D1 | `D1_ns_mms.py` | NS: saddle points, PSPG, steady MMS orders |
| D2 | `D2_lid_driven_cavity.py` | validation against Ghia et al. (1982) |
| D3 | `D3_cylinder.py` | immersed obstacles in flow + force extraction |

Run a chapter from the repo root, e.g.:

```bash
python tutorials/D_flow/D1_ns_mms.py
```

Related solver project page: [`docs/projects/navier-stokes.md`](../../docs/projects/navier-stokes.md).
