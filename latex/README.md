# DiffSim curriculum — LaTeX course packet

Upload this folder to Overleaf (zip it, or connect the git repo) and
compile `main.tex` (pdfLaTeX). Requires only standard packages
(tcolorbox, listings, hyperref — all on Overleaf).

- **Add a chapter**: drop a `.tex` in `chapters/` and add one `\input`
  line in `main.tex` (future tracks are stubbed there: NS-HT, CH-NS,
  NS-PNP).
- **Source of truth**: the runnable scripts in `tutorials/`. Chapters are
  generated by `python tutorials/build_latex.py`; regeneration is MANUAL
  so hand-polish of the generated files survives — polish freely, or
  regenerate after script changes and re-polish.
