# SP-1 R0 Plan — XDD Forward Port (bricks, protocols, observables, parity)

> **For agentic workers:** execute with superpowers:subagent-driven-development
> or the program's supervisor/agent practice (commit-per-green, agents never
> push). Checkboxes (`- [ ]`) track tasks. Spec:
> `docs/dev/specs/2026-07-17-sp1-differentiable-xdd-design.md` (§3, §4, §6, §7-R0).

**Goal:** the GPU-native forward XDD substrate — five-field bricks, closures,
excitation protocols, instrument observables — gated by MMS, reduction,
SimSalabim, CPU parity, and the ≥100× J(t) perf gate. R1 (adjoints) builds on
this untouched.

**Architecture:** a new brick family in the scalar_transport/M2 kernel-factory
idiom (one factory per weak form, `_kernel_cache`, shared `tau_m_metric`),
composed by a monolithic 5-field Newton stepper with a film-front-end-style
config layer (`XDDParams` + preflight + runlog). Every closure sits behind one
differentiable interface so R3's learned heads drop in without refactoring.

**Tech stack:** Warp kernels + the existing assembly/solver stack (cuDSS for
2-D nonsymmetric systems, splu fallback); torch only enters at R1+.

## Global constraints (from the spec — binding on every task)

- Basis-agnostic (arrays only from the factory tabulation); **BDF1 + BDF2**
  cross-matrix per feature (BDF2 deterministic-only).
- Nondimensionalization **identical to the CPU code**: x0=Height, φ0=V_T,
  C0=N_C=2.5e25 m⁻³, μ0=max(μ_n,μ_p), t0=x0²φ0/μ0, U0=μ0φ0C0/x0², J0=U0·x0·q,
  λ²=φ0·ε_m/(x0²C0q).
- **No SUPG on Poisson** (recorded deviation). SUPG (Tezduyar-class τ, M2
  conventions) on carrier drift terms only. Excitons unstabilized.
- k_diss **exact field-coupling in the Jacobian** (deviation from CPU, recorded).
- Exciton sink split 1/τ_x = 1/τ_r + 1/τ_nr from day one (PL needs it).
- Interface masks are **tanh-relaxed in the dist field** (width = named param);
  **no f′** (excluded with reason).
- J reported as (Jny, Jpy, min) — the min only for parity reporting.
- Parity tolerances from measured repeats with **≥2× headroom**; never
  bit-identical. Honest-verdict ledger for every gap.
- Production GPU-only; `.venv/bin/python` on the box; tee-to-file logging;
  never edit a `.py` mid-run (run-lock discipline via `scripts/remote/`).

## Block A — substrate (params, morphology, closures)  [leads]

A1. **`XDDParams` + CPU-config reader.** Dataclass with the full material set
    (both canonical systems), scale derivation exactly as `DDFields.h`
    (x0…λ²), protocol block, closure block. `from_cpu_config(path)` parses the
    CPU `config.txt` names verbatim (mu_n, mu_p, muRatio, eps_A/D, E_g, a,
    interfaceThk, Height, tau_x_*, Gx_*, ret_factor, Voc, refine_lvl, dt,
    solver_strategy…); `.spec` readers (2-column λ/value) for solar,
    absorption, donor-PL files; the RET overlap and spectrum-split G computed
    per `DDFields.h:111-190`.
    *Gate:* scale values vs hand-computed table for the canonical config
    (φ0=0.02585 V at 300 K etc.); RET factor for PM6:Y6 spectra ≈ 0.98-class,
    P3HT:PCBM ≈ 0.08-class (framework-paper values, tolerance on our spectra).

A2. **Morphology module.** Reader for the CPU cloud format; bilinear/nearest
    interpolation to the mesh (CartesianCloud-equivalent); **signed-dist
    utility** (exact Euclidean distance transform on the voxel grid, sign from
    morph label; convention: negative=donor, positive=acceptor — the CPU
    convention); tanh mask `m(dist; w)` and region assignment through it;
    film-npz reader (φ field → threshold → morph+dist). Descriptor export
    (interfacial area, phase fractions) GraSPI-compatible.
    *Gate:* bilayer analytic dist exact; mask limits recover sharp regions as
    w→0; round-trip CPU file → fields → re-export.

A3. **Closures module.** One interface: `closure(fields, aux) -> value, d/d(fields)`
    (analytic derivatives — the R1 contract starts here).
    - `OnsagerBraunDissociation(a, eps, interface_mask)`:
      E_B=q²/(4πεa); b=q³|∇φ|φ0/(8πε(k_BT)²·x0) (re-dimensioned gradient);
      k=(3γ/4πa³)e^(−E_B/k_BT)(1+b+b²/3+b³/18+b⁴/180+b⁵/2700), nondim by
      C0/U0, × per-species scaling. Includes ∂k/∂|∇φ| (the exact-Jacobian
      deviation).
    - `LangevinRecombination(strategy, zeta, spatial)`: γ∈{(q/ε)(μn+μp),
      (q/ε)min, image-force}, ζ∈(0,1], spatial ∈{uniform, interface}.
    - `Generation(profile, waveform)`: profile ∈ {constant, Beer–Lambert
      αΓ0e^(−α x0(1−ĥ)), spectra-split (+RET transfer at interface)};
      waveform w(t) ∈ {CW, step, pulse(t_on), rectified-sin(f), user callable}
      — G(x,t)=G_profile(x)·w(t). **The stub becomes real here.**
    - `RegionMobility(mu_n, mu_p, muRatio, w)`: tanh-blended majority/minority;
      exciton mobilities likewise; ε step with interface average.
    *Gates:* closure unit tests vs hand values (incl. the b-series at known
    field); derivative checks vs FD per closure (1e-8 class, these are
    algebraic); waveform engine reproduces the Nirmal rectified-sinusoid
    sampling exactly.

## Block B — bricks and the coupled solve

B1. **Poisson brick** (λ²-form): −∇·(λ²ε̂∇φ̂)−(p̂−n̂)=0. New factory
    `make_xdd_poisson_Ae/be` (ε̂(x) as GP field; NO stabilization). Strong +
    (later SBM) Dirichlet via the stepper convention.
    *Gate:* MMS orders (p1→2, p2→3), 2-D; ε̂ piecewise field case.

B2. **Carrier bricks** (n̂, p̂): ∂t n̂ + ∇·(−μ̂_n n̂∇φ̂ + μ̂_n∇n̂) − D̂ + R̂ = 0
    (p̂ with drift sign flipped), SUPG with advection velocity ∓μ̂∇φ̂ frozen at
    GPs (the M2 one-way-coupler contract), τ_M = scalar τ with κ→μ̂.
    Sources D̂ = k̂_d X̂_D + k̂_a X̂_A, R̂ = γ̂n̂p̂ via Block-A closures.
    *Gate:* MMS with manufactured φ (orders cross-matrix p1/p2 × BDF1/BDF2);
    drift-dominated Peclet sweep stable where Galerkin oscillates.

B3. **Exciton bricks** (X̂_D, X̂_A): ∂t X̂ − μ̂_X∇²X̂ + (1/τ̂_x + k̂)X̂ =
    Ĝ + R̂_feed (region-assigned back-feed, kept for parity). No SUPG.
    *Gate:* MMS cross-matrix; decay-only case matches exp(−t(1/τ+k)) exactly
    in the spatially-uniform limit.

B4. **Monolithic 5-field Newton.** Node-major dof layout
    [φ, n, p, X_D, X_A]; one assembly pass; full Jacobian incl. ∂D/∂φ (via
    ∂k/∂|∇φ|), ∂R/∂n,p, drift cross-terms. Positivity-guarded line search
    (reject states with n,p < floor). Block-GS mode (exciton KSP ↔ DD SNES,
    `max_block_per_ts`, tol 1e-3/1e-4) kept behind a flag for parity
    debugging. Solver: cuDSS (nonsymmetric LU) with splu fallback.
    *Gate:* coupled MMS (all five fields, orders hold); Newton quadratic on
    the bilayer at V=0 from the continuation IC.

B5. **Log-density option.** u=ln n̂, v=ln p̂ variable change in the carrier
    bricks (drift-diffusion becomes advection with ∇φ̂∓∇u; sources scale by
    e^u). Flagged per-run; primal remains the parity mode.
    *Gate:* same coupled MMS passes in log mode; the e⁻⁶⁰ bilayer BCs solve
    WITHOUT the generation ramp (the robustness payoff, measured vs primal).

## Block C — protocols and marching

C1. **Continuation + march** (`XDDRun`): dark equilibrium at V=0 (G=0 solve
    from neutral IC) → generation ramp (factor-5 ladder to max_G) → voltage
    sweep (V_app stepping with previous-bias IC, STEADY_STATE_JV) — the CPU
    protocol, now a documented contract. BDF1 default march; BDF2 available.
    Adaptive log-space dt (`dt=10^(−ceil(−log10 t))` capped at dt_max), CPU
    steady-state criterion (10 consecutive steps: solution norms <
    time_stepping_tol AND |Jny−Jpy| < 1%·J).
    *Gate:* bilayer V=0 reaches steady state; criterion fires; runlog captures
    the dt/convergence history (4-layer runlog pattern).

C2. **Solver strategies**: {STEADY_STATE_JV, TRANSIENT_JV, PULSE, STEADY_PULSE}
    driving the Generation waveform (light-off at t>pulse_duration for the
    pulse modes).
    *Gate:* STEADY_PULSE on the bilayer — carrier/exciton relaxation after
    light-off is monotone and mass-consistent (post-process integrals, the
    `post_process.txt` quantities reproduced: ∫G, ∫kX, ∫X/τ, ∫γnp, totals).

## Block D — observables

D1. **Consistent-flux J** (bulk-adjacent elements at each contact, the
    DDJscBulk method on M2's consistent-flux machinery): Jny, Jpy,
    re-dimensioned to mA/cm² (J0·0.1); report min for parity. J–V writer
    (`j_v_curve` equivalent), Jsc, FF, Voc-bracketing.
    *Gate:* on the steady bilayer, |Jny−Jpy|/J < 1% (the CPU's own
    self-consistency test).

D2. **J(t) + features.** Trace capture at output cadence; the Nirmal feature
    vector: peak/left-min/right-min/time-avg values, left/right/avg
    amplitudes, rise(10–90%)/fall(90–10%) times, cycle time, phase shift,
    skewness×2, asymmetry; FFT features (H1, THD, odd/even ratio, harmonic
    decay slope). IRF convolution utility (Gaussian σ + user kernel) applied
    to any trace; bandwidth parameter on J(t).
    *Gate:* features on a synthesized analytic trace match closed-form values;
    IRF of a δ-like trace returns the kernel.

D3. **PL observables.** PL_i(t) = ∫ X̂_i/τ̂_r,i dV (per species, optional
    spectral weighting by the donor-PL spec); steady **PL-quench ratio**
    (blend vs. τ-only neat-film reference). Rides STEADY_PULSE for TRPL.
    *Gate:* uniform-slab analytic check: PL(t) ∝ e^(−t/τ_eff) with
    1/τ_eff = 1/τ_r + 1/τ_nr + k̂ in the interface-free limit.

## Block E — the R0 gate battery (each locks a baseline)

E1. **Reduction gates** (M5-G0 style): (i) k_diss→∞ + interface generation
    limit reproduces the CMAME-2012 transport-only model on the 6-stripe
    cases (qualitative J ordering + 1-D quantitative); (ii) 1-D homogeneous
    device vs the Kodali PPV:PCBM validation (Jsc ≈ −30 A/m² class, 120 nm,
    Table-2 parameters).

E2. **SimSalabim cross-check.** 1-D homogeneous bilayer-free device, matched
    parameter set (Koster-2005 conventions mapped in a documented dictionary:
    DOS, μ, ε, E_g→V_bi, Langevin γ, G uniform); J–V overlay, |ΔJsc| and
    |ΔVoc| within the documented tolerance (expect %-class from
    discretization/BC differences; the mapping doc IS a deliverable).

E3. **CPU parity, canonical.** Run `drift_diffusion_ts` (gpubox build) on
    `test/config.txt` + `morph_bilayer_2D.txt` (+specs); run XDD on the same
    inputs via `from_cpu_config`; compare Jsc at V=0 and the STEADY_PULSE
    relaxation. Tolerance from ≥5 CPU repeats, ≥2× headroom. Exciton BC in
    `_ts` mode (natural).

E4. **Framework-table parity.** ≥2 morphologies × 2 systems from Table 1
    (anchor set: P3HT:PCBM bilayer 0.746 / BHJ3 8.303 mA/cm²; PM6:Y6 bilayer
    2.422 / BHJ3 19.810) with the paper parameter table; morphology inputs
    regenerated per the paper's classes (bilayer analytic; BHJ from a CH run
    via the film-npz path — also exercising A2's second reader).

E5. **Perf gate.** The Nirmal configuration (513×129, 1 ns, 10 GHz rectified
    sinusoid, PM6-class parameters): one J(t) trace end-to-end on one GPU;
    target **≥100×** vs the 10–30 h/36-core baseline (i.e. ≤ ~10 min class);
    batched multi-waveform demo (N waveforms sharing one factorization/mesh).
    Locks `tests/baselines/xdd_*.json` + a findings note with the measured
    table.

E6. **Preflight + honest-verdict ledger.** Preflight checks wired (D-class:
    Debye vs h, interface width vs h, dt0 vs stiffness, memory forecast);
    the §6 ledger lands in the dev-notes with measured evidence per item
    (SUPG-on-Poisson delta measured on one case, exciton-BC delta measured,
    min-vs-contact J delta).
