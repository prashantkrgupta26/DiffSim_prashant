# M1c Hero Demo — "Recovering a Hidden GENIE Edit from Flow Measurements"

Scoped with Baskar 2026-07-06. Story: a known last-layer INR edit α\*
(for the bunny: including its trained head-1 ear direction) is applied to
the geometry; downstream velocity probes record the resulting flow; the
optimizer, starting from the unedited shape and seeing ONLY probe data,
recovers the edit through the differentiable Octree-SBM-NS stack.
DiffSim + GENIE in one narrative. State-only QoI — every ingredient is
already gated.

Config: 3-D, L5 box (the measured cuDSS ceiling), Re ~ 100 confined,
window contract per oracle; J = Σ_probes |u − u\*|² (steady) /
Σ_n Σ_probes (transient); modes = thick-band Gram top-k (+ head-1 for
the bunny); optimizer = objective-accepted trust-region steps (the L6
lesson) with per-epoch re-carve; dJ/dν reported from the same sweeps
(M1's constitutive-gradient requirement).

## Ladder (commit-per-green)

- **H1 sphere-INR steady warmup**: hidden α\* (k=4, branch-stable
  magnitude), steady Picard forward, probe QoI, adjoint via the
  drag-gate machinery with the probe functional; FD spot-check at α=0;
  recover α→α\* (convergence plot data). Debugs probe placement + step
  sizes at minimum cost.
- **H2 sphere-INR transient**: same story through TransientShapeAdjoint
  (20 BDF2 steps); validates the headline mechanics.
- **H3 bunny steady**: window the bunny; admissibility gate under
  α-edits; hidden edit includes the head-1 trained direction; recover.
- **H4 bunny transient HEADLINE**: full run + deliverables — gradient
  validation table at the hero config, α→α\* convergence plot,
  before/after INR renders (true smooth geometry), dJ/dν table, honest
  caveats (L5 ear resolution per the band-study rule; w0=1.0 sphere
  caveat).

Known risks & mitigations: bunny admissibility under edits (gate before
optimizing); probe observability of ear edits (place probes in the ear
wake; verify dJ/dα\* ≠ 0 before starting); epoch objective jumps
(objective-accepted steps; probe-mismatch objectives are smoother than
drag); solver time (L5 3-D ~1-2 s/solve — steady epochs ~30 s, transient
~1-2 min/epoch).
