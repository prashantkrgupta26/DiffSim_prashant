**Goal:** establish the P2 forward engine on a trusted footing — the group's
VMS-incremental-Helmholtz-Leray projection stepper (equal-order u/p, BDF2),
**composed with volumetric SBM**, reproducing the M1b flow-past-a-body
benchmarks. R0 is *not* "build a projection stepper": the stepper already
exists (`src/diffsim/steppers/leray.py::LerayProjectionStepper`). R0 is
(a) **audit** that stepper against the published VMS-projection paper and fix
any formulation deviation; (b) **compose** it with volumetric SBM (thread the
shifted-Nitsche vector Dirichlet through all three sub-solves, incl. the
surrogate-consistent BC on the PPE + correction that preserves no-penetration);
(c) **validate** against M1b (NS MMS ±0.10/field, BDF2 order, cylinder Re20
Cd=1.352 + Strouhal Re100, sphere Re300). No shell, no adjoint, no HT.

**Architecture:** one new thin module `src/diffsim/steppers/leray_sbm.py`
holds `LeraySBMStepper`, which **composes** (does not fork)
`LerayProjectionStepper` with an immersed-geometry oracle. It takes a
`Sphere`/`TriMesh`/SDF oracle instead of a body-fitted `g_fn`, runs the
per-epoch surrogate pipeline (`classify_lambda` → `extract_surrogate` →
`GeometryData.evaluate` from `src/diffsim/sbm/surrogate.py`), builds the
geometry-only SBM face block ONCE (`sbm_vector_dirichlet` from
`src/diffsim/sbm/vector.py`), and injects it into each of the three
sub-solves of the base stepper via a small set of hooks added to
`leray.py` (predictor block add; PPE surrogate-consistent boundary rows;
correction trace). `LerayProjectionStepper` itself is modified **only** where
the §4 parity audit requires it — every change carries a one-line note citing
the paper equation. Cd/Strouhal come from `surrogate_traction`
(`sbm/vector.py`). The M1b test fixtures (`tests/test_cylinder.py`,
`tests/test_sphere.py`, `tests/test_cylinder_strouhal.py`,
`tests/test_cavity.py`) are the validation precedent and are reused, not
forked.

**Tech Stack:** numpy/scipy host reference (`splu` for all three sub-solves via
`diffsim.solvers.linsolve.solve_linear`), the existing warp device NS brick
(`api/ns_bricks.py::assemble_linear_ns`) for the predictor volume block, warp
SBM face kernels (`sbm/vector.py`, `sbm/poisson.py`), `solvers/timestepping.py`
(`bdf_coeffs`, `bdf_order_now`, `History`) for BDF1/BDF2. Device solve path

## Key finding — the stepper already exists (verified by reading the code)

`src/diffsim/steppers/leray.py::LerayProjectionStepper` is already an
incremental VMS-Helmholtz-Leray projection stepper with the three sub-solves:
1. **nonlinear predictor** — Picard (default) / Newton over the monolithic
   `assemble_linear_ns` block with **all pressure DOFs pinned to `p*`**
   (`leray.py` step() lines ~176–221), strong Dirichlet rows from `g_fn` at
   `self.dir_nodes`;
2. **PPE** — SPD scalar Poisson `self.K_p` (or `_weighted_stiffness` under the
   `ppe_finescale` flag), pinned at free-node 0 for enclosed flow, solving the
   **increment** `φ = p̂ − p*` (lines ~222–285);
3. **correction** — consistent-mass L2 projection
   `u = ũ − (1/σ)∇φ` (`self.M`, lines ~286–307), then strong Dirichlet on the
   updated trace, then `p* ← p̂`, `hist.rotate`.
It uses `bdf_coeffs`/`bdf_order_now`/`History` and `tau_hbased_host` ("Eq. 45").
`divergence_l2()` is the solenoidality diagnostic.

**What it is NOT (verified):** it is **not SBM-coupled**. It consumes
body-fitted `f_fn`/`g_fn` (`__init__(self, dm, nu, dt, f_fn, g_fn, ...)`) and
applies strong Dirichlet at box `boundary_nodes` — there are **no SBM hooks,
no surrogate face set, no `sbm_vector_dirichlet` call** anywhere in the file.
That coupling is R0's real work. Composing the SBM face block into all three
sub-solves is done in Tasks 2–4.

## Task 3 — surrogate-consistent BC on the pressure-Poisson + correction

**Nature:** the no-penetration-preserving piece. Impose the surrogate-consistent
boundary condition on the **PPE (Step 2)** and the **correction (Step 3)** so
the Leray projection preserves the blockage (no-penetration) property at the
immersed body — exactly the BC-consistency the solution-transfer paper proves
necessary. R0 wires it for the **static** immersed body (moving/adaptive
transfer projection is R3).

- *modify:* `src/diffsim/steppers/leray.py` — allow the PPE assembly/solve and
  the correction to receive a surrogate-face boundary contribution (a scalar
  Neumann/Nitsche flux on `sf` enforcing `∇φ·n̂` consistent with the corrected
  velocity's no-penetration, and the trace handling in the correction so the
  SBM-governed velocity is not overwritten by box-Dirichlet).
- *modify:* `src/diffsim/steppers/leray_sbm.py` — pass the surrogate flux into
  the base PPE/correction hooks.
- *test (modify):* `tests/test_p2r0_projection_sbm.py::test_ppe_surrogate_consistent_no_penetration`.

**Interfaces (consumes):**
- `GeometryData` fields `geo.xq, geo.d, geo.n, geo.corr` (surrogate GP
  geometry) and `SurrogateFaces(sf.elem, sf.face)`; `face_gauss_points(tree,
  sf, ftab)`; face tables via `diffsim.mesh.faces.face_tables(pv, dim)`.
- The base PPE path in `leray.py` (`self.K_p` / `_weighted_stiffness`,
  `rhs_free`, the free-node-0 pin) and the correction mass path (`self.M`,
  the per-component RHS integral).
- `LerayProjectionStepper.divergence_l2()` for the tolerance check.

**Produces:** the PPE now solves the increment `φ` subject to the
surrogate-consistent boundary flux on `sf` (so the projected velocity has zero
normal component *at the surrogate*, up to `geo.corr` area correction), and the
correction preserves the SBM no-penetration trace. No new public signature
beyond the internal hook.

**Design note (the physics R0 must get right):** the classic Leray projection
on a box takes homogeneous Neumann `∂φ/∂n = 0` on do-nothing outflow and pins
the enclosed case. With an immersed body, the projection's boundary condition
on `sf` must be **surrogate-consistent**: the normal-flux boundary term uses
`geo.n` and the `geo.corr` area correction so that the correction
`û = ũ − σ⁻¹∇φ` has the *shifted* no-penetration `û·n̂ ≈ 0` at the true
boundary — this is what prevents the projection from re-introducing penetration
that the predictor's SBM Dirichlet removed. Wire the flux as the surrogate-face
contribution to the PPE RHS/operator (host-side, `face_gauss_points` + `geo`),
mirroring the `surrogate_traction` face-loop structure in `sbm/vector.py`.
