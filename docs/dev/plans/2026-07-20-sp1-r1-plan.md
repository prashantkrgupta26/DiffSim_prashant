a unified `Control` interface with three control classes, two gradient-verified
adjoint modes (implicit steady-state and taped frozen-dt transient),
differentiable instrument QoIs that expose per-parameter sensitivity rows, the

**Architecture:** one new module `src/diffsim/xdd/adjoint.py` holds the `Control`

`IlluminationControl`), and the two adjoint drivers (`XDDSteadyAdjoint`,
`XDDTransientAdjoint`). The drivers reuse the R0 assembler (`XDDSystem`), the
implicit-function-theorem reverse-solve pattern from
`src/diffsim/adjoint/phasefield.py::CHAdjoint`, the checkpointed frozen-dt
reverse-sweep pattern from `src/diffsim/sbm/transient_adjoint.py::TransientAdjoint`,
and the transposed direct solve `splu(A.T.tocsc()).solve(rhs)` (the
`src/diffsim/sbm/adjoint.py::solve_adjoint` idiom), promoting to
`diffsim.solvers.linsolve.solve_linear(A.T, rhs, solver="cudss")` on the box.
`observables.py` is EXTENDED (not forked) with the differentiable QoI faces.

**Tech Stack:** numpy/scipy (host reference, `splu` transpose solve), the R0
warp device assembler (`exciton_device.py`) + `solvers/linsolve.py`

## R0 facts every task relies on (read these before starting)

- **5-field block structure** (`exciton_system.py`): field order `IPHI,IN,IP,IXD,IXA
  = 0..4`, `NDOF=5`. State is a dict `{field: full_nodal_vector[n_nodes]}`. The
  constraint operator `sysm.T` (csr, `n_nodes×n_free`), `sysm.free`,
  `sysm.n_free`.
- **Assembly entry point:** `sysm.assemble_newton_system(state, need_matrix=True)`
  → `(A, r)`. Host path: `A = sysm._reduce_and_eliminate(sysm.jacobian_full(state),
  sysm.residual_full(state))`. `A` is a `5·n_free × 5·n_free` scipy CSR in
  **field-major** dof layout (`row = field*n_free + free_idx`) on the host path;
  **node-major** (`row = node*NDOF + field`) on the device path. The Newton
  Jacobian at a converged state is exactly `A = ∂R/∂u` (with Dirichlet identity
  rows). Mode A uses `Aᵀ`.
- **Closure derivative contract (A3):** `LangevinRecombination(n,p,dist) ->
  (R_hat, dR_dn, dR_dp)` with `R_hat = γ̂·n̂·p̂`, `γ̂ = zeta*γ*C0²/U0`;
  `OnsagerBraunDissociation(gmag,dist) -> (k_hat_d, k_hat_a, (dk_dgrad_d,
  dk_dgrad_a))`. These return `d/d(fields)` only; R1 controls ADD `d(closure)/d(param)`.
- **Generation source:** `sysm.set_generation(gd_gp, ga_gp)` sets per-bin GP
  dicts `{pv: ndarray[ne*nqp]}`; the residual’s exciton rows carry `+M(Ĝ_i)`
  through `_load_block`. An `IlluminationControl` perturbs `gd_gp/ga_gp`.
- **Forward observables (do not duplicate):** `contact_flux_pair(sysm,state)`,
  `designated_current(Jny,Jpy,contact)`, `build_jv_curve`, `extract_jsc_ff`,
  `pl_species_integral(sysm,state,tau_r_inv_hat,field_index,weight)`,
  `pl_trace(...)`. `IXD=3, IXA=4`.
- **Transient march recorder:** `run._march_to_steady(...)` returns
  `(final_state, march_info)` with `march_info["step_history"]` (per accepted
  step: `t_hat, dt_hat, jny, jpy, accepted`, optional `post_process`). Mode B
  adds a checkpointing march that additionally records the converged full state
  per step.

- Produces (relied on by Tasks 2–7):
  - `class Control(Protocol)` with:
    - `name: str`
    - `size: int`  (1 for scalar controls; k for a vector control)
    - `get() -> np.ndarray`   (always returns a `(size,)` array)
    - `set(p: np.ndarray) -> None`
    - `residual_vjp(sysm, state, seed_full) -> np.ndarray`  — given an adjoint
      seed on the FULL residual (`seed_full`: dict `{field: nodal_vector}` OR a
      flat `5·n_free` vector; the driver passes a flat reduced-space `λ`),
      returns `∂R/∂pᵀ · seed` as a `(size,)` array.
    - `sensitivity_rows(sysm, state) -> np.ndarray` — returns `∂R/∂p` as a
      `(size, 5·n_free)` array (the reduced-space residual Jacobian rows; the
      row-basis for requirement 2).
  - `class ClosureControl(Control)` for a single scalar closure parameter,
    constructed as `ClosureControl(sysm, param="langevin_zeta")` where `param ∈
    {"langevin_zeta", "ex_diss_d_scaling", "ex_diss_a_scaling"}`.

**Design notes for the implementer:**
- `residual_vjp` and `sensitivity_rows` share one primitive: `dR_dp_full(sysm,
  state) -> np.ndarray[(size, 5·n_free)]`, the reduced-space residual derivative.
  `residual_vjp` returns `dR_dp_full @ seed_flat`; `sensitivity_rows` returns
  `dR_dp_full` directly. Implement `dR_dp_full` once, reuse.
- The reduced residual for field `f` is `sysm.T.T @ R_full[f]` (matches
  `_reduce_and_eliminate`’s `r = concatenate([T.T @ R[f] ...])`). So a
  per-field full-space residual derivative `dRfull[f]` maps to reduced space by
  `sysm.T.T @ dRfull[f]`, concatenated field-major into a `5·n_free` vector.
- `ClosureControl` derivative is ANALYTIC where the A3 form is linear in the
  parameter (Langevin `R̂ = γ̂·n̂·p̂` is linear in `zeta` since `γ̂ ∝ zeta`;
  Onsager `k̂_d ∝ ex_diss_d_scaling`), so `∂R̂/∂zeta = R̂/zeta` and
  `∂k̂_d/∂scaling = k̂_d/scaling` at GPs. The residual’s dependence: for the
  Langevin `zeta`, the carrier rows carry source `−R̂` and the exciton rows
  carry feed `+R̂` (see `residual_full`), so `∂R[IN]/∂zeta = ∂R[IP]/∂zeta =
  −∂(load from R̂)/∂zeta` and `∂R[IXD]/∂zeta = ∂R[IXA]/∂zeta = +...`. Assemble
  the perturbation exactly as `residual_full` assembles the `R̂` contribution,
  with the GP field `R̂/zeta` in place of `R̂` (reuse `_mass_block`/`_load_block`).

```python
from tests._xdd_adjoint_fixtures import build_small_lit_system  # Task 1 helper


def _fd_residual_dp(sysm, state, control, eps_rel=1e-6):
    """Central-FD of the reduced residual w.r.t. the control's scalar param."""
    p0 = control.get().copy()
    eps = eps_rel * max(1.0, abs(float(p0[0])))
    control.set(p0 + eps)
    Rp = _reduced_residual(sysm, state)
    control.set(p0 - eps)
    Rm = _reduced_residual(sysm, state)
    control.set(p0)
    return (Rp - Rm) / (2 * eps)          # shape (5*n_free,)


def _reduced_residual(sysm, state):
    from diffsim.physics.exciton_system import NDOF
    R = sysm.residual_full(state)
    return np.concatenate([np.asarray(sysm.T.T @ R[f]) for f in range(NDOF)])
```

```python
    Uses a mild Eg_hat and a reduced-drive config so a short BDF march reaches
```

```python
# src/diffsim/xdd/adjoint.py
"""SP-1 R1 — differentiable XDD adjoint machinery.

The Control interface (the unit of "a thing we differentiate with respect to"),
the three R1 control classes, and the two adjoint drivers (implicit steady-state
Mode A, taped frozen-dt transient Mode B) specialised to the XDD 5-field system.
Reuses the R0 assembler (exciton_system / exciton_device), the phasefield IFT
reverse idiom, the sbm transient-adjoint checkpointing lineage, and the
splu(A.T)/solve_linear transposed solve — nothing is forked.
"""
from __future__ import annotations

from typing import Protocol, runtime_checkable

import numpy as np

from diffsim.physics.exciton_system import (
    NDOF, IPHI, IN, IP, IXD, IXA,
    _mass_block, _load_block)


def _reduce_full(sysm, R_full):
    """Field-major reduce of a per-field full residual dict to (5*n_free,)."""
    return np.concatenate([np.asarray(sysm.T.T @ R_full[f])
                           for f in range(NDOF)])


@runtime_checkable
class Control(Protocol):
    name: str
    size: int
    def get(self) -> np.ndarray: ...
    def set(self, p: np.ndarray) -> None: ...
    def residual_vjp(self, sysm, state, seed_flat: np.ndarray) -> np.ndarray: ...
    def sensitivity_rows(self, sysm, state) -> np.ndarray: ...


class ClosureControl:
    """A single scalar closure parameter: Langevin prefactor (via zeta) or an
    Onsager dissociation scaling.  The A3 closures are LINEAR in these
    parameters, so the residual derivative is assembled analytically by
    re-running the R̂/k̂ contribution with the parameter-derivative GP field."""

    _SUPPORTED = ("langevin_zeta", "ex_diss_d_scaling", "ex_diss_a_scaling")

    def __init__(self, sysm, param: str):
        if param not in self._SUPPORTED:
            raise ValueError(f"ClosureControl: unknown param {param!r}")
        self.name = param
        self.size = 1
        self._sysm = sysm

    # -- read/write the live parameter on the closure objects ----------------
    def get(self) -> np.ndarray:
        s = self._sysm
        if self.name == "langevin_zeta":
            return np.array([float(s.langevin.zeta)])
        if self.name == "ex_diss_d_scaling":
            return np.array([float(s.onsager.params.ex_diss_d_scaling)])
        return np.array([float(s.onsager.params.ex_diss_a_scaling)])

    def set(self, p: np.ndarray) -> None:
        import dataclasses
        s = self._sysm
        v = float(np.asarray(p).ravel()[0])
        if self.name == "langevin_zeta":
            s.langevin = dataclasses.replace(s.langevin, zeta=v)
        else:
            s.onsager = dataclasses.replace(
                s.onsager, params=s.onsager.params.replace(**{self.name: v}))

    # -- the shared primitive: dR/dp as reduced-space rows (size, 5*n_free) --
    def _dR_dp_full(self, sysm, state) -> np.ndarray:
        dm = sysm.dm
        cl = sysm._closures(state)
        dR = {f: np.zeros(dm.n_nodes) for f in range(NDOF)}
        z_aq = {pv: np.zeros((len(sysm.dist_gp[pv]), dm.dim)) for pv in dm.bins}
        if self.name == "langevin_zeta":
            zeta = float(sysm.langevin.zeta)
            # R̂ is linear in zeta -> dR̂/dzeta = R̂/zeta at GPs
            dRhat = {pv: cl["R"][pv] / zeta for pv in dm.bins}
            # carrier rows: source is (D̂ − R̂) entering via −load; exciton feed
            # +R̂.  Mirror residual_full's assembly with dRhat in place of R̂.
            fcar = {pv: -dRhat[pv] for pv in dm.bins}       # d(−R̂)/dzeta
            Fn = _load_block(dm, sysm._aq(cl["gradphi"], sysm.mu_n_gp, -1.0),
                             sysm.mu_n_gp, fcar, sysm._sig2tau(), sysm.supg)
            Fp = _load_block(dm, sysm._aq(cl["gradphi"], sysm.mu_p_gp, +1.0),
                             sysm.mu_p_gp, fcar, sysm._sig2tau(), sysm.supg)
            # residual R[IN] = Kn@n − Fn, so ∂R[IN]/∂zeta = −∂Fn/∂zeta
            dR[IN] = -Fn
            dR[IP] = -Fp
            fex = {pv: dRhat[pv] for pv in dm.bins}          # d(+R̂ feed)/dzeta
            Fxd = _load_block(dm, z_aq, sysm.mu_xd_gp, fex, 0.0, 0.0)
            Fxa = _load_block(dm, z_aq, sysm.mu_xa_gp, fex, 0.0, 0.0)
            dR[IXD] = -Fxd
            dR[IXA] = -Fxa
        else:
            # Onsager scaling: k̂_i linear in the scaling -> dk̂/ds = k̂/s.
            # Dissociation D̂ = k̂_d X̂_D + k̂_a X̂_A enters carrier source +D̂ and
            # the exciton sink (σ_tot,i carries +k̂_i) via K@X.  Only the
            # scaled species' k̂ moves.
            fld_key = "kd" if self.name == "ex_diss_d_scaling" else "ka"
            xkey = "xd_gp" if self.name == "ex_diss_d_scaling" else "xa_gp"
            xfld = IXD if self.name == "ex_diss_d_scaling" else IXA
            sval = float(self.get()[0])
            dk = {pv: cl[fld_key][pv] / sval for pv in dm.bins}
            # carrier source +D̂ contribution d/ds = dk·X̂  (enters −load)
            dDs = {pv: dk[pv] * cl[xkey][pv] for pv in dm.bins}
            Fn = _load_block(dm, sysm._aq(cl["gradphi"], sysm.mu_n_gp, -1.0),
                             sysm.mu_n_gp, dDs, sysm._sig2tau(), sysm.supg)
            Fp = _load_block(dm, sysm._aq(cl["gradphi"], sysm.mu_p_gp, +1.0),
                             sysm.mu_p_gp, dDs, sysm._sig2tau(), sysm.supg)
            dR[IN] = -Fn
            dR[IP] = -Fp
            # exciton sink K@X̂ with σ_tot carrying +k̂_i: dR[xfld]/ds = M(dk·X̂)
            M_dkx = _mass_block(dm, dk) @ state[xfld]
            dR[xfld] = M_dkx
        return _reduce_full(sysm, dR)[None, :]     # (1, 5*n_free)

    def sensitivity_rows(self, sysm, state) -> np.ndarray:
        return self._dR_dp_full(sysm, state)

    def residual_vjp(self, sysm, state, seed_flat: np.ndarray) -> np.ndarray:
        return self._dR_dp_full(sysm, state) @ seed_flat
```

```python
class MaterialControl:
    """A scalar material/transport parameter that enters the R0 residual terms.

    param -> term perturbed:
      "mu_n"       carrier n-row drift+diffusion+SUPG (mu_n_gp ∝ mu_n)
      "mu_p"       carrier p-row (mu_p_gp ∝ mu_p)
      "mu_x_donor" exciton D-row diffusion (mu_xd_gp ∝ mu_x_donor)
      "tau_inv_d"  exciton D-row sink σ_tot,D diagonal: dR[IXD]/dtau = M X̂_D
      "tau_inv_a"  exciton A-row sink: dR[IXA]/dtau = M X̂_A
    """
    _SCALARS = ("tau_inv_d", "tau_inv_a")
    _MUFIELDS = {"mu_n": "mu_n_gp", "mu_p": "mu_p_gp",
                 "mu_x_donor": "mu_xd_gp"}

    def __init__(self, sysm, param: str):
        if param not in self._SCALARS and param not in self._MUFIELDS:
            raise ValueError(f"MaterialControl: unknown param {param!r}")
        self.name = param
        self.size = 1
        self._sysm = sysm
        # capture the current magnitude so a µ GP field can be scaled/derived
        if param in self._MUFIELDS:
            self._field = self._MUFIELDS[param]
            self._val0 = float(np.max([np.max(np.abs(getattr(sysm, self._field)[pv]))
                                       for pv in sysm.dm.bins]))

    def get(self) -> np.ndarray:
        s = self._sysm
        if self.name in self._SCALARS:
            return np.array([float(getattr(s, self.name))])
        # scalar handle = current scale multiplier (1.0 at construction)
        return np.array([1.0])

    def set(self, p: np.ndarray) -> None:
        s = self._sysm
        v = float(np.asarray(p).ravel()[0])
        if self.name in self._SCALARS:
            setattr(s, self.name, v)
        else:
            # scale the µ GP field about its construction value
            base = getattr(self, "_base_field", None)
            if base is None:
                base = {pv: getattr(s, self._field)[pv].copy() for pv in s.dm.bins}
                self._base_field = base
            setattr(s, self._field, {pv: v * base[pv] for pv in s.dm.bins})

    def _dR_dp_full(self, sysm, state) -> np.ndarray:
        from diffsim.physics.exciton_system import (_carrier_block,
                                                    _exciton_block)
        dm = sysm.dm
        cl = sysm._closures(state)
        dR = {f: np.zeros(dm.n_nodes) for f in range(NDOF)}
        if self.name == "tau_inv_d":
            dR[IXD] = _mass_block(dm, {pv: np.ones(len(sysm.dist_gp[pv]))
                                       for pv in dm.bins}) @ state[IXD]
        elif self.name == "tau_inv_a":
            dR[IXA] = _mass_block(dm, {pv: np.ones(len(sysm.dist_gp[pv]))
                                       for pv in dm.bins}) @ state[IXA]
        elif self.name in ("mu_n", "mu_p"):
            fld = self._field
            base = getattr(self, "_base_field",
                           {pv: getattr(sysm, fld)[pv] for pv in dm.bins})
            # d(mu_gp)/dscale = base; re-assemble the carrier block with base
            sign = -1.0 if self.name == "mu_n" else +1.0
            aq = {pv: sign * base[pv][:, None] * cl["gradphi"][pv] for pv in dm.bins}
            Kd = _carrier_block(dm, aq, base, sysm.sigma, sysm._sig2tau(), sysm.supg)
            f = IN if self.name == "mu_n" else IP
            dR[f] = Kd @ state[f]
        else:  # mu_x_donor
            base = getattr(self, "_base_field",
                           {pv: getattr(sysm, "mu_xd_gp")[pv] for pv in dm.bins})
            sig_d = {pv: np.zeros(len(sysm.dist_gp[pv])) for pv in dm.bins}
            Kd = _exciton_block(dm, base, sig_d)     # pure μ_X K (σ part zero)
            dR[IXD] = Kd @ state[IXD]
        return _reduce_full(sysm, dR)[None, :]

    def sensitivity_rows(self, sysm, state):
        return self._dR_dp_full(sysm, state)

    def residual_vjp(self, sysm, state, seed_flat):
        return self._dR_dp_full(sysm, state) @ seed_flat


class IlluminationControl:
    """Generation control.  mode='scalar': overall intensity (size 1).
    mode='vector': a per-height-band piecewise illumination profile (size
    n_bands) — the requirement-1 vector control (∂R/∂p is (n_bands, 5*n_free)).

    Generation enters ONLY the exciton rows via _load_block(feed Ĝ_i), so the
    residual derivative is a pure exciton-row load with ∂g/∂pⱼ = base-generation
    restricted to band j (vector) or the whole base generation (scalar)."""

    def __init__(self, sysm, dist_gp, gen, mode="scalar", n_bands=1, h_axis=1):
        self._sysm = sysm
        self._gen = gen
        self.name = "illumination"
        self.mode = mode
        # base generation GP fields (the current set_generation values)
        self._gd0 = {pv: sysm._gd[pv].copy() for pv in sysm.dm.bins}
        self._ga0 = {pv: sysm._ga[pv].copy() for pv in sysm.dm.bins}
        if mode == "scalar":
            self.size = 1
            self._p = np.array([1.0])
            self._masks = None
        else:
            self.size = int(n_bands)
            self._p = np.ones(self.size)
            self._masks = self._band_masks(sysm, h_axis, n_bands)  # per-bin,per-band

    def _band_masks(self, sysm, h_axis, n_bands):
        # GP nondim height per bin -> band index -> boolean masks
        from diffsim.physics.exciton_system import _gp_value
        dm = sysm.dm
        coords = dm.mesh.node_coords
        hc = coords[:, h_axis]; lo, hi = hc.min(), hc.max()
        hhat_nodal = (hc - lo) / max(hi - lo, 1e-30)
        hgp = _gp_value(dm, hhat_nodal)      # {pv: ndarray[ngp]}
        masks = {}
        edges = np.linspace(0.0, 1.0, n_bands + 1)
        for pv in dm.bins:
            b = np.clip(np.digitize(hgp[pv], edges[1:-1]), 0, n_bands - 1)
            masks[pv] = [(b == j) for j in range(n_bands)]
        return masks

    def get(self):
        return self._p.copy()

    def set(self, p):
        self._sysm  # keep handle
        p = np.asarray(p, float).ravel()
        self._p = p.copy()
        dm = self._sysm.dm
        if self.mode == "scalar":
            gd = {pv: p[0] * self._gd0[pv] for pv in dm.bins}
            ga = {pv: p[0] * self._ga0[pv] for pv in dm.bins}
        else:
            gd = {}; ga = {}
            for pv in dm.bins:
                w = np.zeros_like(self._gd0[pv])
                for j, m in enumerate(self._masks[pv]):
                    w[m] = p[j]
                gd[pv] = w * self._gd0[pv]; ga[pv] = w * self._ga0[pv]
        self._sysm.set_generation(gd, ga)

    def _dR_dp_full(self, sysm, state):
        dm = sysm.dm
        z_aq = {pv: np.zeros((len(sysm.dist_gp[pv]), dm.dim)) for pv in dm.bins}
        rows = np.zeros((self.size, NDOF * sysm.n_free))
        for j in range(self.size):
            if self.mode == "scalar":
                dgd = {pv: self._gd0[pv] for pv in dm.bins}
                dga = {pv: self._ga0[pv] for pv in dm.bins}
            else:
                dgd = {pv: np.where(self._masks[pv][j], self._gd0[pv], 0.0)
                       for pv in dm.bins}
                dga = {pv: np.where(self._masks[pv][j], self._ga0[pv], 0.0)
                       for pv in dm.bins}
            dR = {f: np.zeros(dm.n_nodes) for f in range(NDOF)}
            Fxd = _load_block(dm, z_aq, sysm.mu_xd_gp, dgd, 0.0, 0.0)
            Fxa = _load_block(dm, z_aq, sysm.mu_xa_gp, dga, 0.0, 0.0)
            dR[IXD] = -Fxd     # R[IXD] = Kxd@X − Fxd
            dR[IXA] = -Fxa
            rows[j] = _reduce_full(sysm, dR)
        return rows

    def sensitivity_rows(self, sysm, state):
        return self._dR_dp_full(sysm, state)

    def residual_vjp(self, sysm, state, seed_flat):
        return self._dR_dp_full(sysm, state) @ seed_flat
```

```python
# ── R1 differentiable QoI faces (steady) ─────────────────────────────────────
class SteadyCurrentQoI:
    """Differentiable designated contact current as a steady QoI.

    value = designated_current(Jny, Jpy, contact); the adjoint flows from
    dJ/du, the reduced-space seed.  Jny = Σ_anode (Kn(σ=0,SUPG=0) @ n̂), so
    ∂Jny/∂n̂ = Knᵀ e_anode and ∂Jny/∂φ̂ is the drift dependence of Kn on ∇φ̂.
    """
    def __init__(self, contact="anode", h_axis=1):
        self.contact = contact
        self.h_axis = h_axis

    def value(self, sysm, state) -> float:
        jny, jpy = contact_flux_pair(sysm, state, h_axis=self.h_axis)
        return designated_current(jny, jpy, contact=self.contact)

    def dJ_du(self, sysm, state) -> np.ndarray:
        from diffsim.physics.exciton_system import (_carrier_block,
                                                    _poisson_block, NDOF,
                                                    IPHI, IN, IP)
        dm = sysm.dm
        cl = sysm._closures(state)
        coords = dm.mesh.node_coords
        hc = coords[:, self.h_axis]; lo, hi = hc.min(), hc.max()
        if self.contact == "anode":
            wall = np.where(np.abs(hc - lo) < 1e-9)[0]
            mu_gp, fld, sign = sysm.mu_n_gp, IN, -1.0
        else:
            wall = np.where(np.abs(hc - hi) < 1e-9)[0]
            mu_gp, fld, sign = sysm.mu_p_gp, IP, +1.0
        aq = {pv: sign * mu_gp[pv][:, None] * cl["gradphi"][pv] for pv in dm.bins}
        Kc = _carrier_block(dm, aq, mu_gp, 0.0, 0.0, 0.0)
        e = np.zeros(dm.n_nodes); e[wall] = 1.0
        # ∂J/∂c = Kcᵀ e   (c = n̂ or p̂)
        dJ_dc = Kc.T @ e
        # ∂J/∂φ̂ = Σ_wall ∂(Kc@c)/∂φ̂ = drift-cross of coeff (sign·μ̂·c) seeded by e
        cdrift = {pv: sign * mu_gp[pv] * cl["n_gp" if fld == IN else "p_gp"][pv]
                  for pv in dm.bins}
        Kphi = _poisson_block(dm, cdrift, 1.0)     # ∫ coeff (∇N_b·∇N_a)
        dJ_dphi = Kphi.T @ e
        sign_out = 1.0 if (contact_flux_pair(sysm, state, h_axis=self.h_axis)[
            0 if self.contact == "anode" else 1] >= 0) else -1.0
        dR = {f: np.zeros(dm.n_nodes) for f in range(NDOF)}
        dR[fld] = sign_out * dJ_dc
        dR[IPHI] = sign_out * dJ_dphi
        return np.concatenate([np.asarray(sysm.T.T @ dR[f]) for f in range(NDOF)])

    def dJ_dp(self, sysm, state, control) -> np.ndarray:
        return np.zeros(control.size)      # pure-state QoI


class JVMisfitQoI:
    """Full-curve misfit Σ (J_model(V) − J_data(V))²; single-bias reduced form
    for R1 (the driver evaluates it at the held operating bias, one term).
    dJ/du = 2 (J_model − J_data) · dJ_model/du."""

        return 2.0 * r * self._cur.dJ_du(sysm, state)

        return np.zeros(control.size)
```

```python
class XDDSteadyAdjoint:
    """Mode A — implicit steady-state adjoint for the XDD 5-field system.

    At a converged state R(u;p)=0, A=∂R/∂u is the Newton Jacobian (R0
    device-assembled).  Solve Aᵀλ=∂J/∂u ONCE, reuse the factorization across
    observable seeds; dJ/dp = ∂J/∂p − λᵀ ∂R/∂p per registered control."""

    def __init__(self, sysm, controls):
        self.sysm = sysm
        self.controls = list(controls)
        self._A = None

    def factorize(self, state):
        A, _ = self.sysm.assemble_newton_system(state)
        self._A = A.tocsr()
        return self

    def _solve_T(self, rhs):
        try:
            from diffsim.solvers.linsolve import solve_linear
            return solve_linear(self._A.T.tocsr(), rhs, solver="cudss",
                                cache={}, cache_key="xdd_r1_steady")
        except Exception:
            from diffsim.sbm.adjoint import solve_adjoint
            return solve_adjoint(self._A, rhs)     # splu(A.T).solve(rhs)

    def gradient(self, state, qoi) -> dict:
        if self._A is None:
            self.factorize(state)
        lam = self._solve_T(qoi.dJ_du(self.sysm, state))
        out = {}
        for c in self.controls:
            djdp = qoi.dJ_dp(self.sysm, state, c)      # (size,)
            out[c.name] = djdp - c.residual_vjp(self.sysm, state, lam)
        return out

    def sensitivity_rows(self, state, obs_seeds) -> np.ndarray:
        """obs_seeds: (n_obs, 5*n_free) array of ∂o/∂u.  Returns ∂o/∂p as
        (n_obs, n_p_total) with the p-columns ordered by self.controls.  Reuses
        the SAME factored Aᵀ across all seeds (requirement 2 / R3 Fisher rows)."""
        if self._A is None:
            self.factorize(state)
        n_obs = obs_seeds.shape[0]
        # per control, ∂R/∂p rows (size, 5*n_free)
        dRdp = [c.sensitivity_rows(self.sysm, state) for c in self.controls]
        cols = sum(c.size for c in self.controls)
        rows = np.zeros((n_obs, cols))
        for k in range(n_obs):
            lam = self._solve_T(obs_seeds[k])
            off = 0
            for c, dr in zip(self.controls, dRdp):
                rows[k, off:off + c.size] = -(dr @ lam)
                off += c.size
        return rows
```

```python
def march_with_checkpoints(sysm, state, *, dt0_hat, dt_max_hat, max_steps,
                           order=1, newton_kw=None, h_axis=1):
    """BDF march that CHECKPOINTS the converged full state + exact dt/BDF
    metadata per accepted step (host) — the Mode-B transient-adjoint tape.
    Adaptive dt on the FORWARD is fine; the recorded dt's are what the reverse
    sweep freezes.  Returns (final_state, steps)."""
    nk = newton_kw or {}
    t_hat = 0.0; dt_hat = dt0_hat
    prev = {f: state[f].copy() for f in range(NDOF)}
    prev2 = None
    steps = []
    gd, ga = sysm._gen()
    for _ in range(max_steps):
        use_order = 2 if (order == 2 and len(steps) >= 1 and prev2 is not None) else 1
        new_state, info = sysm.step_bdf(state, dt_hat, order=use_order,
                                        prev=prev, prev2=prev2, **nk)
        if not info["converged"]:
            dt_hat *= 0.5
            if dt_hat < 1e-20:
                break
            continue
        t_hat += dt_hat
        steps.append({"state": {f: new_state[f].copy() for f in range(NDOF)},
                      "prev": {f: prev[f].copy() for f in range(NDOF)},
                      "prev2": (None if prev2 is None
                                else {f: prev2[f].copy() for f in range(NDOF)}),
                      "dt_hat": dt_hat, "order": use_order,
                      "sigma": sysm.sigma, "t_hat": t_hat,
                      "gd": {pv: gd[pv].copy() for pv in sysm.dm.bins},
                      "ga": {pv: ga[pv].copy() for pv in sysm.dm.bins}})
        prev2 = {f: prev[f].copy() for f in range(NDOF)}
        prev = {f: new_state[f].copy() for f in range(NDOF)}
        state = new_state
        dt_sched = _dt_schedule(t_hat, dt_hat, dt0_hat, dt_max_hat)
        dt_hat = max(dt_sched, dt_hat)
    return state, steps
```

```python
class XDDTransientAdjoint:
    """Mode B — taped transient (frozen-dt) adjoint over a checkpointed march.

    Reuses the sbm/transient_adjoint record-then-reverse pattern for the XDD
    5-field stepper: reverse sweep, per-step transposed solve Aₙᵀλₙ=seedₙ+pendₙ,
    BDF history cotangent coupling on the time-stepped fields {IN,IP,IXD,IXA}
    (φ̂ excluded — no time term), per-step control VJPs.  dt is FROZEN from the
    recorded values (the backward pass never re-adapts)."""

    _TFIELDS = (IN, IP, IXD, IXA)

    def __init__(self, sysm, controls, steps):
        self.sysm = sysm
        self.controls = list(controls)
        self.steps = steps

    def _rebuild_AT(self, rec):
        s = self.sysm
        s.sigma = rec["sigma"]
        hist_full = self._hist_full(rec)
        s.hist = {f: _gp_value_hist(s, hist_full[f]) for f in range(NDOF)}
        s.set_generation(rec["gd"], rec["ga"])
        s._current_state = rec["state"]
        A, _ = s.assemble_newton_system(rec["state"])
        return A.tocsr()

    def _hist_full(self, rec):
        # mirror step_bdf's history construction (frozen at recorded dt/order)
        dt = rec["dt_hat"]
        if rec["order"] == 1 or rec["prev2"] is None:
            hist = {f: (1.0 / dt) * rec["prev"][f] for f in range(NDOF)}
        else:
            hist = {f: (2.0 * rec["prev"][f] - 0.5 * rec["prev2"][f]) / dt
                    for f in range(NDOF)}
        hist[IPHI] = np.zeros(self.sysm.dm.n_nodes)
        return hist

    def _solve_T(self, A, rhs):
        try:
            from diffsim.solvers.linsolve import solve_linear
            return solve_linear(A.T.tocsr(), rhs, solver="cudss",
                                cache={}, cache_key="xdd_r1_transient")
        except Exception:
            from diffsim.sbm.adjoint import solve_adjoint
            return solve_adjoint(A, rhs)

    def gradient(self, dJdx_list, qoi=None) -> dict:
        s = self.sysm; nf = s.n_free
        N = len(self.steps)
        grads = {c.name: np.zeros(c.size) for c in self.controls}
        pending = [np.zeros(NDOF * nf) for _ in range(N)]
        Mfull = _mass_block(s.dm, {pv: np.ones(len(s.dist_gp[pv]))
                                   for pv in s.dm.bins})
        for n in range(N - 1, -1, -1):
            rec = self.steps[n]
            A = self._rebuild_AT(rec)
            rhs = dJdx_list[n] + pending[n]
            lam = self._solve_T(A, rhs)
            for c in self.controls:
                grads[c.name] -= c.residual_vjp(s, rec["state"], lam)
            # history cotangent to earlier steps (frozen dt/order)
            dt = rec["dt_hat"]
            coeffs = ([(1, 1.0 / dt)] if rec["order"] == 1 or rec["prev2"] is None
                      else [(1, 2.0 / dt), (2, -0.5 / dt)])
            for k, ck in coeffs:
                if n - k < 0:
                    continue
                for f in self._TFIELDS:
                    lam_f = lam[f * nf:(f + 1) * nf]
                    # map reduced λ_f through Mᵀ (mass symmetric) into the
                    # earlier step's seed on field f
                    contrib = ck * (s.T.T @ (Mfull @ (s.T @ lam_f)))
                    pending[n - k][f * nf:(f + 1) * nf] += contrib
        return grads

    def sensitivity_rows(self, obs_seed_list) -> np.ndarray:
        """Requirement-2 transient rows: reuse gradient() per observable seed
        list, stacking ∂o/∂p across controls."""
        cols = sum(c.size for c in self.controls)
        out = np.zeros((len(obs_seed_list), cols))
        for i, seeds in enumerate(obs_seed_list):
            g = self.gradient(seeds)
            off = 0
            for c in self.controls:
                out[i, off:off + c.size] = g[c.name]
                off += c.size
        return out
```

```python
# ── R1 differentiable QoI faces (transient) ──────────────────────────────────
class TRPLMisfitQoI:
    """TRPL decay misfit Σ_n (PL(tₙ) − PL_data(tₙ))².  PL(tₙ) = Σ_i weight_i·
    (1/τ̂_r,i)·∫X̂_i dV̂ (the R0 pl_species_integral), LINEAR in the nodal X̂ so
    the per-step exciton seed is exact."""
    def __init__(self, target_decay, weight_donor=1.0, weight_acceptor=1.0,
                 params=None):
        self.target = [float(x) for x in target_decay]
        self.wd = float(weight_donor); self.wa = float(weight_acceptor)
        self._params = params

    def _pl(self, sysm, state):
        p = self._params if self._params is not None else _params_of(sysm)
        trd = _tau_r_inv_hat(p, "donor"); tra = _tau_r_inv_hat(p, "acceptor")
        pl_d = pl_species_integral(sysm, state, trd, IXD, weight=self.wd)
        pl_a = pl_species_integral(sysm, state, tra, IXA, weight=self.wa)
        return pl_d + pl_a

    def value(self, sysm, steps) -> float:
        return sum((self._pl(sysm, s["state"]) - self.target[n]) ** 2
                   for n, s in enumerate(steps))

    def dJ_dx_list(self, sysm, steps):
        from diffsim.physics.exciton_system import IXD as _IXD, IXA as _IXA, NDOF
        p = self._params if self._params is not None else _params_of(sysm)
        trd = _tau_r_inv_hat(p, "donor"); tra = _tau_r_inv_hat(p, "acceptor")
        seeds = []
        for n, s in enumerate(steps):
            r = self._pl(sysm, s["state"]) - self.target[n]
            gD = _pl_integral_grad_nodal(sysm, _IXD, trd, self.wd)   # (n_nodes,)
            gA = _pl_integral_grad_nodal(sysm, _IXA, tra, self.wa)
            seed = {f: np.zeros(sysm.dm.n_nodes) for f in range(NDOF)}
            seed[_IXD] = 2.0 * r * gD
            seed[_IXA] = 2.0 * r * gA
            seeds.append(np.concatenate([np.asarray(sysm.T.T @ seed[f])
                                         for f in range(NDOF)]))
        return seeds


def _pl_integral_grad_nodal(sysm, field_index, tau_r_inv_hat, weight):
    """∂(∫ w·X̂/τ̂_r dV)/∂X̂_nodal = weight·(1/τ̂_r)·(Nᵀ dV) — the GP-quadrature
    adjoint of the nodal→GP interpolation used by pl_species_integral."""
    dm = sysm.dm
    h_all = dm.mesh.tree.h()
    g = np.zeros(dm.n_nodes)
    for pv, b in dm.bins.items():
        conn = dm.mesh.conn_of[pv]
        N = dm.tables_by_p[pv].N               # [nqp, nbf]
        eids = dm.mesh.bins[pv]; he = h_all[eids]
        jac = (0.5 * he) ** dm.dim; nqp = b["nqp"]
        wt = dm.tables_by_p[pv].w; ne = len(eids)
        dV = (np.tile(wt, ne) * np.repeat(jac, nqp)).reshape(ne, nqp)
        # contribution to node a: Σ_q dV[e,q] N[q,a]
        ge = np.einsum("eq,qa->ea", dV, N)     # [ne, nbf]
        np.add.at(g, conn.ravel(), ge.ravel())
    return weight * tau_r_inv_hat * g


def _params_of(sysm):
    """Best-effort XDDParams handle for τ̂_r (attached by the fixture/driver)."""
    p = getattr(sysm, "params", None)
    if p is None:
        raise ValueError("TRPLMisfitQoI needs params: pass params=... or set "
                         "sysm.params")
    return p
```
