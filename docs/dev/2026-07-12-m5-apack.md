## 1. A1 — temperature as a field

DESIGN.  Nodal T(x, t) solved as a SEGREGATED linear step per BDF1
attempt (`TemperatureField`): rho_cp dT/dt = div(k_th grad T) + s,
host-scipy assembly (consistent mass + stiffness, one LU per dt
value), Dirichlet substrate/ambient rows by replacement, insulated
natural BCs otherwise.  SPLITTING CHOICE (recorded): Lie split — T
advances on [t, t+dt] from the committed field FIRST, then the
crystallization step reads T^{n+1} at quadrature points.  Splitting
error O(dt), the same order as BDF1: no temporal-order degradation.
T commits only on ACCEPTED steps (ladder-consistent; a rejected
attempt discards its T solve).

FIELD COUPLING.  In field mode the kernel computes the crystal
driving PER GP (p1: dh(1 - T/Tm); r14: dh(T/Tm - 1)); the host passes
dh in the drive slot + Tm + GP-interpolated T.  Scalar mode keeps the
host-side drive path BIT-IDENTICALLY (compile-time flag; the S0
fixed-dt parity re-measured 8.27e-15 after the kernel revision,
identical to the pre-A-pack lock).  chi(T): NOT parameterized in this
brick (constant chi inputs); a future chi(T) law must read the same
per-GP Tq array (plumbing exists — recorded).  FDT noise amplitude
stays the global calibration knob; spatially-varying kBT(x) noise is
a recorded frontier.  D(T) HOOK: optional Arrhenius factor
exp(-Ea (1/T - 1/T_ref)) on the CH mobility per GP (fastmode lam,
_n-mode Vignes D_i, const-mob Ons), both T modes.  M_psi(T) (WLF on
the AC prefactor) is a recorded follow-up.

## 2. A2 — substrate surface energy

DESIGN.  F_w = Int_{Gamma_w} (g_i phi_i + h_i phi_i^2) dS over
retained species; natural-BC term in the mu_i rows (weak form in the
module docstring A2: kap dphi/dn = -f_w'), consistent P1 face mass
host-assembled in full node space (the wodo top-flux pattern),
Jacobian block -2 h_i Mw on (mu_i, phi_i).  Face-generic:
wall_face = (axis, side); default (1, 0) = y = 0.  wall_g = wall_h
= 0 bypasses the machinery entirely (wall_on flag) — the g = 0

QUADRATIC-TERM PHYSICS NOTE (measured during gate design): f_w' =
g + 2 h phi vanishes at phi* = -g/(2h) — the wall RESTORES phi toward
phi*, so h > 0 with |g| < 2 h phi_bulk DEPLETES a phi_bulk = 0.5 film
(phi* < 0.5) rather than "saturating the enrichment"; the quadratic
gate asserts the restoring direction on both sides of phi*.

### 4b. BDF2 (variable-step, deterministic)

DESIGN.  tstep="bdf1" (default, unchanged path) | "bdf2": standard
variable-coefficient BDF2, r = dt_n/dt_{n-1}, a = (1+2r)/(1+r),
b = 1+r, c = r^2/(1+r); BDF1 bootstrap on the first step.  BDF2 rides
the SAME kernel (time term sigma*x - hist per GP): the host passes
sigma = a/dt and hist = (b x^n - c x^{n-1})/dt — ZERO kernel change.
Ladder consistency: rejects never mutate the history; coefficients
recompute from the actual (dt, dt_prev) per attempt.  The
frozen-theta bookkeeping row stays the EXACT identity under BDF2
(a = b - c, equal histories => theta^{n+1} = theta^n).  SCOPE LIMIT
(recorded): deterministic only — noise_psi = noise_phi = 0 asserted;
the FDT-noise weak order under BDF2 is out of scope.
