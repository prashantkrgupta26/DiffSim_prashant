## Block A — Heat + Mass bricks and the coupler (LEADS)

A1. **Scalar advection-diffusion brick** (temperature): volume kernel in
    the NS kernel family (same factory pattern, SUPG/VMS tau consistent
    with the flow stabilization); strong + Nitsche + SBM Dirichlet,
    SBM Neumann (Eq.21 path is validated); p1 AND p2 (scalar p2 exists).
    Gates: MMS orders 2-D/3-D, p1/p2; SBM variants on the immersed disk
    at r=0.27-class radii (dyadic rule!).
A2. **Mass brick**: the same kernel family instantiated for species
    (coefficient set + boundary types). This is the brick-genericity
    proof: ONE factory, two physics. Gate: MMS + a Sh case mirroring A4.
A3. **One-way coupler** (forced convection): NS velocity advects the
    scalar within the stepper's block structure (scalar step after each
    NS step; shared GP fields — reuse the device GP arrays).
    Gates: coupled MMS; **heated immersed cylinder** Nu(Re=10-40) vs
    correlations (the SBM+thermal composition gate).
A4. **Boussinesq two-way**: buoyancy source term into NS momentum.
    Gate: **de Vahl Davis** differentially heated cavity, Ra 1e3-1e6,
    Nu vs the tabulated benchmark (the tight coupler gate).
A5. **Thermal adjoints**: taped scalar kernels (findings-4c rules);
    dNu/dkappa (constitutive), d(Nu)/d(boundary data), transient chain
    extension through the coupled step. Gates: three-way on the heated
    cavity; transient chain at the H2 tolerance class.

## Block B — Neural closures in-the-loop (the S2 demo)

B1. Differentiable coefficient FIELDS first: kappa(x)/nu(x) as GP-level
    inputs; adjoint dJ/d(field) (the ns_volume_cotangents pattern
    generalized). Gate: three-way on cavity + heated cavity.
B2. **Closure MLP**: nu_t(features; theta), features = (shear rate,
    wall distance, ...); torch composition dJ/dtheta =
    (dJ/d nu_field) @ (d nu_field/d theta) — our adjoint chains into
    torch autograd (the provided-INR composition pattern, applied to a
    network WE train; the geometry no-training rule does NOT apply to
    closures).
B3. **Retrain demo** (the milestone's S2 deliverable): hide a target
    closure, generate flow data, recover theta by in-loop training.
    Mirrors the hero-recovery pattern; lessons from 4f apply (signal
    scale checks BEFORE optimizing — the H4 protocol).

## Block C — p2-NS (the M1 amendment repaid)

C1. p2 vector NS bricks (volume + face; the p2 shift carries the
    Hessian term — machinery from the band study).
C2. p2 taped kernels (findings-4c rules; expect unroll pressure — the
    residual-form trick from 4e is the fallback).
C3. Gates: cavity benchmarks at p2; cylinder Cd; SBM-NS with a p2 band
    around the obstacle (the composition that motivated the band).

## Block D — FINALE: the bunny headline

The measured recipe (findings H4-final): **L5 flow + transient
DRAG-HISTORY observables (traction_functional + face_dbar_sweep — both
gated) + ear-dominant edits** (mode 0 = the checkpoint's semantic
direction, 45x the ripple signal). Protocol hardening from the failures:
signal-scale check before optimizing (J0 must clear the 4f noise floor),
guarded GN (trust-region cap at the epoch bound), anchored feet +
marginal-GP borrow. Deliverables: recovery table + alpha-trajectory
plots, renders (bunny + edited bunny + flow), dJ/dnu table at the hero
config, the M2 report.
